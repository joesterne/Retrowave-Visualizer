# Web Audio Player

A retro-style music player built with React, Web Audio API, and Tailwind CSS. It features a Winamp-inspired interface, custom audio visualizers, and a popout window mode.

## Features

- **Retro Interface**: Winamp-style controls and layout
- **Custom Visualizers**: Spectrum, Oscilloscope, Plasma, Bars, and Dots modes
- **Popout Visualizer**: A separate window for full-screen visualization synchronization
- **Firebase Integration**: User authentication and favorites tracking
- **AI Radio**: Powered by Gemini AI for generating thematic playlists

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Configure your `.env` variables based on `.env.example`
4. Run `npm run dev` to start the development server

## Tech Stack

- React 18+
- Tailwind CSS
- Web Audio API
- Firebase (Firestore & Auth)
- Gemini API
- Vite + Express
